# FortniteAimbot

External AI aimbot for Fortnite. Uses a YOLOv8 TensorRT model running on your GPU to detect players through DXGI screen capture, with an ImGui overlay and serial output to a Raspberry Pi Pico for hardware mouse movement.

---

## What it does

- **AI detection** — YOLOv8n model accelerated with TensorRT FP16, runs inference on a cropped FOV region around your crosshair for accurate detection at any range
- **Hardware aimbot** — sends mouse deltas over serial to a Raspberry Pi Pico acting as a USB HID device, bypassing software mouse hooks entirely
- **Sticky lock** — once a target is acquired the crosshair hard-locks onto the head dot with no smoothing drift; releases only when the key is let go or the target disappears
- **ESP overlay** — external DirectX 11 transparent overlay draws bounding boxes, head dots, tracers and confidence percentages over the game window
- **Self-mask** — configurable region that excludes your own player model from detections
- **Full ImGui menu** — INSERT to toggle, tabbed layout (Main / Combat / Mask / Config), all settings save to `config.ini`

---

## Requirements

- Windows 10/11 x64
- NVIDIA GPU (Pascal or newer, CUDA 12.4 capable)
- Raspberry Pi Pico flashed as USB HID mouse (connected via USB)
- TensorRT 10.x for CUDA 12.x — **requires free NVIDIA developer account**

Everything else the installer handles automatically.

## Setup

### 1. Clone the repo

```powershell
git clone https://github.com/hutsflutsje/FN.AI.git
cd FortniteAimbot
git submodule update --init --recursive
```

### 2. Download TensorRT (manual — NVIDIA login required)

1. Go to https://developer.nvidia.com/tensorrt
2. Download **TensorRT 10.x for CUDA 12.x — ZIP, Windows**
3. Extract so the layout is:
```
C:\TensorRT\
  bin\
  include\
  lib\
```

### 3. Run the installer

Open PowerShell **as Administrator**:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
.\install.ps1
```

The installer will:
- Install Git, CMake, Python 3.11, VS Build Tools 2022 and CUDA 12.4 automatically
- Export your `.pt` model to ONNX and build a TensorRT FP16 engine
- Configure and build the project in Release mode
- Copy all required DLLs next to the executable

When it finishes:

```
build\Release\AIToolkitOverlay.exe
```

### 4. Place your model

Put your trained `best.pt` (or `yolov8n.pt` as a fallback) in the repo root before running the installer. The installer exports it to `models\best.onnx` and builds `models\best.engine` automatically.

If you already have a `best.engine` the export step is skipped.

## Pico setup

Flash your Raspberry Pi Pico with a USB HID mouse firmware that reads serial commands in the format:

```
dx,dy\n
```

e.g. `-3,7\n` moves the mouse left 3, down 7. Set the COM port in the menu Config tab (default `COM7`).

---

## Controls

| Key | Action |
|---|---|
| `INSERT` | Toggle menu |
| Right Mouse (default) | Activate aimbot |
| Left Mouse (default) | Anti-recoil hold |

All keys are rebindable in the menu.

---

## Menu tabs

| Tab | Contents |
|---|---|
| **Main** | Aimbot, ESP, Tracers, Sticky Lock toggles + key bindings |
| **Combat** | Speed, Strength, Smoothing, Humanize, FOV, Anti-recoil, Triggerbot |
| **Mask** | Self-mask region position and size |
| **Config** | Confidence threshold, class ID, COM port, Save/Load |

```powershell
cmake --build build --config Release
```

## Project structure

```
FortniteAimbot/
  src/
    main.cpp              — main loop, Aimbot + Overlay orchestration
    aimbot.cpp            — target acquisition, serial output, sticky lock
    overlay.cpp           — DX11 transparent window, ImGui menu + ESP draw
    tensorrt_infer.cpp    — DXGI capture, FOV crop, TRT inference, NMS
  include/
    aimbot.h              — Config struct, Aimbot class
    overlay.h             — Overlay class
    tensorrt_infer.h      — TensorRTInference class, Detection struct
  models/
    best.pt               — source weights (you provide)
    best.onnx             — auto-generated by installer
    best.engine           — auto-generated by installer
  externals/
    imgui/                — git submodule
  install.ps1             — full dependency installer
  CMakeLists.txt
  config.ini              — runtime settings (auto-saved by menu)
```
